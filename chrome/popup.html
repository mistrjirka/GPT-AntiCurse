How does this make long chats faster?

A long ChatGPT chat can contain far more internal nodes than messages you actually see—tool calls, system state and hidden items. ChatGPT's page JavaScript repeatedly walks that large conversation graph. AntiCurse removes unnecessary nodes before the page receives the conversation, so those repeated walks operate on a much smaller graph. In All visible history mode, your visible user/assistant turns are preserved. Processing stays local in the browser.

Counters measure graph/data removed, not an estimated CPU percentage.
